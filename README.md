## Featured Projects

### [Deep-RegimeNet](https://github.com/Iandavidk/mscfe_capstone_deep_regime_net)
*MScFE 690 Capstone | WorldQuant University | 2026*

Unsupervised deep learning framework for financial market regime identification,
combining a Temporal Autoencoder (2-layer LSTM, 256 hidden, temporal attention
pooling) with Deep Embedded Clustering (DEC) in a joint optimisation framework.
Trained on 30 years of S&P 500 daily OHLCV data; benchmarked against Gaussian HMM,
DTW-KMeans, Sequential AE+KMeans, and a Naïve Volatility Quantile baseline.

Key result: Gaussian HMM achieves Sharpe 0.850 and total return 1,817% vs
Deep-RegimeNet Sharpe 0.284 — a rigorous negative result showing DEC-based deep
temporal clustering cannot overcome cluster collapse and temporal incoherence at
financial daily-data sample sizes without explicit temporal regularisation.

`Python` `PyTorch` `LSTM` `Deep Embedded Clustering` `Time Series` `Finance`
